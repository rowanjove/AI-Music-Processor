# 音频验收与人工评价规范 (Audio Acceptance & Listening Protocol)

本文档规范 AI Music Processor 的音频质量验收标准、合成 Golden 基准体系、A/B 盲听规程与人工听审评价闭环。

---

## 1. 核心原则：工程事实与听感评价解耦

在 AI 音乐处理流水线中，**客观工程指标通过不等于主观听感改善**。系统建立五维独立的质量事实模型：

1. **音频有效性 (Audio Validity)**：导出文件完整解码无损坏、格式头与音频流一致；
2. **物理指标 (Audio Metrics)**：峰值电平、削波点数、真实时长、残余对齐误差在容差范围内；
3. **阶段完整度 (Processing Integrity)**：流水线各处理阶段完整执行，无降级跳过；
4. **模型运行 (Model Inference)**：真实执行了 AI 模型推理，而非旁路复制；
5. **主观听感 (Listening Quality)**：必须经由人工试听评估并记录结果。

> [!IMPORTANT]
> 在缺乏人工试听记录时，系统质量状态**固定为 `READY_FOR_EXTERNAL_VALIDATION`，听审状态固定为 `not_assessed`**。严禁将算法执行成功包装为“专业级音质已通过”。

---

## 2. 合成 Golden 基准数据集 (Synthetic Golden Set)

为确保测试环境的高确定性、可复现性以及避免侵权与私人素材泄露，Golden 基准采用纯数学公式实时合成，杜绝任何外部音乐片段进入代码仓库。

### 2.1 支持的合成音频场景 (`SYNTHETIC_KINDS`)

| 场景标识 | 信号特征 | 验证目的 |
|---|---|---|
| `silence` | 全零样本 (PCM 16-bit) | 验证降噪、门限与能量检测，避免在无声段产生噪声放大 |
| `clipping` | 2.5倍幅度正弦波，[-1.0, 1.0] 削波截断 | 验证过载削波修复、去破音 (De-clip) 及动态控制稳定性 |
| `mono_tone` | 440 Hz 单声道正弦波 (A4) | 验证单声道输入识别、通道复制与立体声扩展保护 |
| `sample_rates` | 1000 Hz 纯音 (22050/44100/48000 Hz) | 验证重采样一致性、频响保真与抗混叠滤波 |
| `short_impulse` | 前 10 采样点瞬态脉冲 (0.9)，后续静音 | 验证瞬态响应、预回声 (Pre-echo) 抑制及母带压限包络 |
| `phase_inverted` | 左声道 440 Hz，右声道 -440 Hz (反相) | 验证单声道下混消除、相位相关性分析与单声道兼容性 |
| `discontinuous` | 440 Hz -> 0.2s 静音 -> 880 Hz 突变信号 | 验证分段衔接平滑度、窗函数淡入淡出及无爆音截断 |

### 2.2 Golden 规格定义与容差约束

每个 Golden 样例（`create_golden_spec`）冻结输入哈希、运行参数与预期指标。比对时使用严格的工程容差：

- **True Peak 容差**：`|measured - expected| <= 0.01`
- **时长偏差容差**：`|measured - expected| <= 0.03` 秒
- **削波样本点容差**：`0`（容忍度为 0，不得产生新增削波）
- **对齐残余误差 (Residual)**：10~30ms 警告 (`WARN`)，>30ms 阻断 (`FAIL`)

## 3. 同起点 A/B 盲听与响度匹配规程

### 3.1 响度匹配原则 (Loudness Matching)

人类听觉对响度极其敏感，微小的音量提升（甚至 0.5 dB）都会在主观上造成“声音更清晰、动态更好”的假象。
因此，A/B 试听必须遵循：

1. **同起点与同时长**：A 与 B 截取自相同的时间偏移点（例如指定共同起点 0.5s，截取 15s）；
2. **电平归一化 / RMS 匹配**：默认启用响度匹配（`match_loudness=True`），自动计算基准片段有效 RMS 并对对比片段应用等响度增益，并辅以硬峰值防削波保护（最大峰值 <= 0.98）；
3. **源文件只读**：试听提取写入临时预览目录，源文件保持绝对只读，提取前后比对 SHA-256。

## 4. 人工听审闭环与数据记录

### 4.1 结构化缺陷标签体系 (`DEFECT_TAGS`)

听审者在试听对比时，记录客观存在的瑕疵标签：

- `distortion`（破音/过载）：瞬态过载、削波杂音、失真粗糙感；
- `robotic`（电音/机械感）：RVC 或音高修正带来的机械相位感、金属颤音；
- `sibilance`（齿音过重）：高频齿音尖锐、嘶嘶声刺耳；
- `bleed`（串音残留）：人声伴奏分离不彻底、人声轨含有残留伴奏或鼓点；
- `muffled`（声音发闷）：高频衰减严重、动态受损、空间感塌陷；
- `sync_drift`（节奏/对齐漂移）：人声与伴奏未对齐、延迟或节拍错位。

### 4.2 评价持久化与匿名化规范

1. **本地存储**：评价结果保存至用户数据目录 `%LOCALAPPDATA%\AI_Music_Processor\listening_evaluations\eval_<case_id>_<hash>.json`；
2. **隐私与去标识化**：导出汇总报告（`export_anonymized_listening_summary`）时，对试听者姓名进行 SHA-256 掩码（例如 `evaluator-3a7b8c1d`），不向外泄露真实姓名；
3. **放行门禁**：仅当同时具备完整的模型推理执行证据与有效的人工听审记录时，流水线才允许评定为 `QUALITY_ACCEPTED`。
